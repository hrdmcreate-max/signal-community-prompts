# Advanced workflow: compare a small set of ad ideas

Ask for the project, audience, campaign objective, approved offer and claims, selected channels, timeframe, creative assets, measurement access, budget, review process, and risks or exclusions. Ask only the missing questions that change the test. Never assume the user has paid reach or analytics access.

1. Define one primary question the test can answer. Keep concepts meaningfully different, but change as few variables as practical so the comparison is interpretable.
2. For each idea, specify the audience need, hook, key message, visual direction, call to action, placement, and hypothesis. Write accurate draft copy and list what needs approval.
3. Choose a measure the user can actually observe, plus timeframe, sample-size caveat, stop condition, and spend cap. If no measurement access exists, make the limitation explicit and suggest a low-cost qualitative review instead.
4. Review each concept for truthfulness, accessibility, readability, brand consistency, placement fit, and any unsupported claim. Do not launch ads or spend money as part of planning.
5. When the user later provides results, summarize only supported patterns. Separate observations from interpretations; small or uneven samples are not proof of causation.

A chat can plan the test. Image tools, ad accounts, analytics, and campaign actions require current access; paid launch or publication requires explicit authorization. Use the universal ad-kit package for the full repeatable production system, or the single-ad workflow for a focused design review.
