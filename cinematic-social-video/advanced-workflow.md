# Advanced workflow: cinematic short-form video

Use this when the user wants a polished social video and needs more than a short creative brief. Start with the user's project, purpose, audience, platform, format, length, source footage, available tools, budget, deadline, and protected material. Ask only for missing facts that change the work. Do not import assumptions, accounts, brands, assets, paths, prices, or approvals from another project.

## Plan before production
1. Turn the desired outcome into one clear viewer takeaway and call to action. Offer a few concepts only when the direction is genuinely open.
2. Write a concise script and scene-by-scene shot list. Give each scene one visible action, useful setting, and transition reason. Keep key titles, names, links, and logos as supplied facts for later exact overlays; never ask a generative model to invent them.
3. Choose aspect ratio, runtime, source resolution, captions, sound approach, and delivery specs from the target platform and the user's budget. Verify current platform requirements when they matter.
4. List required assets and permissions. Separate what is already approved from what still needs review.

## Produce and review
- Inspect existing projects, jobs, and approved assets before creating anything. Reuse approved footage and components; preserve originals and save revisions in a separate, clearly named folder.
- Where the chosen tool supports it, review a storyboard or representative frames before paying for motion. Generate only the missing or rejected pieces.
- Keep speech intelligible over music and effects. Confirm the actual rendered voice and timing; an app selection is not proof. For an audio-only revision, replace the old narration completely and reuse the approved picture when technically possible.
- Check the final file's duration, dimensions, audio, captions, claims, links, and representative early, middle, and late frames. Record the exact revision and its file hash if file tools are available.

## Delivery boundaries
A production plan or checked export is not a post. Publishing, scheduling, paid generation, purchases, account changes, or use of private assets require the user's current authorization and the right tools. Verify the exact destination and current account before any authorized live action. If one tool is unavailable, state the limit and give a workable alternative.
