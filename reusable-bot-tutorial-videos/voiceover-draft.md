# Voiceover draft

A tutorial should leave someone able to do the task, not just admire the screen. This prompt helps you choose one useful feature, explain it in plain language, and plan a demo people can follow. Tell it who’s watching, what they need to learn, and what tools or footage you have. It turns that into a script and shot plan, and flags steps that need a current version or safe test account. Start with one task people often ask you about.
