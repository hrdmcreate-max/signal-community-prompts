# Advanced workflow: design and review one image ad

Start from one user-approved offer or message. Ask for their project, audience, action they want viewers to take, exact approved claims and dates, visual assets, placement dimensions, tools, budget, and items that must remain unchanged. Ask only for material gaps.

Create a one-page art direction: hierarchy, focal point, setting or image treatment, color/contrast intent, safe area, and the exact copy in reading order. Separate literal copy from the image prompt. Preserve supplied logos and product details; don't invent prices, outcomes, badges, testimonials, or eligibility.

If the user wants a generated image, write a prompt for the tool they selected and describe any text/logo that must be added later as an exact overlay. If no image tool is available, provide a production-ready brief for a designer. Review the result at actual placement size for claim accuracy, spelling, readability, contrast, crop, brand fit, accessibility, and any invented lettering/details. State issues and suggested corrections; don't claim exact logo reproduction if the tool cannot guarantee it.

Save drafts separately from approved assets and record which revision was reviewed. Paid generation, account access, scheduling, and publication require the user's selected tools and explicit authorization. Use this workflow for the focused single-ad task; the ad-kit package contains the larger campaign system.
