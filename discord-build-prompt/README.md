# Clean Up Your Discord

**What it helps with:** Make a business, class, or community server easier to navigate and maintain.

**Where to use it:** Use the starter prompt in Claude Code or another capable AI chat. For a live server audit, the assistant needs an authorized Discord connection or equivalent admin tool; otherwise provide the server details or map yourself.

**What to bring:** Your community purpose, what members should get from it, current layout or audit access, available tools, what must stay protected, and who approves changes.

The prompt asks for critical missing context, shows a proposed map, and waits for your approval before reorganization. It does not assume that you have admin access or that every community needs the same sections.

Any AI service may apply its own plan or usage limits; check the terms for the tool you choose. No image generation is needed for a server map and copy. List the channels, roles, content, or settings you want protected, and changes wait until you approve the proposed map. A live review or server change requires the right Discord access.

Full workflow: see the [complete workflow](complete-workflow.md) for a full map-first, approval-led process.
