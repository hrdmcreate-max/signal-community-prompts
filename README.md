# The Signal Ultimate Prompts

Practical, adaptable prompts and workflows for business, creative, and community projects. Each package is designed to start with your situation: tell the AI what you are building, who it is for, what outcome you want, what tools and time you have, and what must stay protected. The prompt should ask for important missing details and adapt the workflow to your answers.

## Start here

1. Choose a package below and open its `README.md`.
2. Copy its `starter-prompt.md` into a capable AI chat or coding assistant.
3. Give it your own project or community context, audience, desired result, constraints, available tools, and approval process. Keep passwords, API keys, and other secrets out of the chat.
4. Open `complete-workflow.md` for the full instructions and source reference. Use `advanced-workflow.md` for a shorter checklist; related templates are in each package.
5. Set your approval preferences up front. The assistant should work within that scope and pause for changes you reserved for review, new spending, or irreversible actions.

AI chat can help plan and draft. Work that touches local files, generates media, accesses an account, or publishes content also needs an appropriate tool and authorization. A prompt alone does not grant access or perform those actions.
