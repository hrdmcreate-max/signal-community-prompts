# Advanced workflow: build and test an image-ad system

Use this full workflow when a user wants a repeatable ad process, not a single image. Start with their business/project, product or cause, audience, campaign goal, approved offer and claims, channels and placements, assets, tools/accounts, budget, review capacity, and details that must stay private. Ask only for critical missing information. Never carry over another brand's facts or credentials.

## Brief and concept
1. Fill in an intake brief with the audience, objective, desired action, offer facts and dates, approved wording, visual identity, placements, constraints, budget, and approver. Leave unknowns explicitly blank.
2. Choose a small number of distinct concepts. For each, state the audience insight, main message, intended action, visual approach, and what the concept is testing.
3. Write exact draft copy separately from the visual-generation prompt. Keep essential words and logos as user-supplied overlays; do not expect image models to render critical text accurately.
4. Adapt concepts to each selected format. Check legibility at phone size, contrast, safe margins, crop, brand consistency, accessibility, and platform fit.

## Build and review
- Use only user-approved assets and claims. Flag unsupported claims, missing rights, uncertain offers, or expired dates for human review.
- Generate only when the user chooses an available image tool and confirms any required spend. Keep prompt, seed/settings if available, source assets, output filename, and revision together.
- Review spelling, exact offer, logo use, invented product details, readable hierarchy, likeness/rights concerns, and fit to placement. Never present a concept as approved until the user says so.
- Maintain a simple asset manifest, quality checklist, cost ledger, and publication record. The supporting CSV templates are optional and can be adapted; don't create empty bookkeeping if the project doesn't need it.

## Test and improve
Choose one primary variable to compare at a time where practical, such as hook, benefit, or visual treatment. Define the audience, placements, dates, spend cap, success measure, and a stop condition before launch. Use real results only; note sample size and uncertainty. Do not promise outcomes or infer a winner from too little evidence. Refresh platform rules, links, prices, and account state before any live campaign.

## Boundaries
Text planning can happen in an AI chat. Image generation needs an image tool; file preparation needs suitable file tools; publishing or paid advertising requires the user's selected account, authorized access, and explicit approval. Never buy credits, launch spend, connect accounts, or publish on an implied approval.
