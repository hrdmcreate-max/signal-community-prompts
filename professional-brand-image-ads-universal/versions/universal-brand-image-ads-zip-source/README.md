# Image Ad Production Starter Kit

**What it helps with:** Move from a brand brief to image-ad concepts, usable prompts, captions, and review-ready files.

**Where to use it:** Paste the starter prompt into an AI chat. Image generation and file preparation need tools you select.

**What to bring:** Bring your identity, audience, desired outcome, approved facts, assets, placements, available tools, budget, and review preferences.

The starter prompt asks about your project and desired outcome, checks for critical gaps, then adapts its help to your answers. It does not assume every reader has the same tools or account access. Any paid service, account connection, or public action remains subject to your choice and authorization.
