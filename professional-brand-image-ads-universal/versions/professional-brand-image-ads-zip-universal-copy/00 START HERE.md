# Universal brand kit — quick start

This is the client-neutral package. Bring your own brand identity, real assets, offers, account choices, dates, and current permissions.

1. Copy 01 UNIVERSAL MASTER PROMPT.txt into a capable chat.
2. Attach your brand packet and complete 03 BRAND INTAKE TEMPLATE.md where possible.
3. The agent prefills known facts and asks only missing groups, up to ten.
4. It discovers/verifies selected business accounts and checks the live scheduler tier/capacity.
5. Complete official secure sign-in/access steps when required.
6. Review the actual representative image and feasible calendar.
7. In your chosen execution mode, the agent produces the batch, checks every asset/caption, schedules within scope, and verifies the native queue.
8. Save the final records for recovery and next month.

For images only, use 04 IMAGE PROMPT AND EDIT TEMPLATES.txt.
For the full process, read 02 HOW TO RUN THE SYSTEM.md.
For a first-month plan and style comparisons, read 05 FIRST MONTH AND TESTING PLAYBOOK.md.
For resuming/recurring work, read 06 RECOVERY AND AUTOMATION.md.
For review scenarios, read 08 SCENARIO ACCEPTANCE TESTS.md.

The blank CSVs in templates are internal records, not a scheduler import schema.
No secrets belong in this folder.
Documentation does not connect accounts or install an always-running agent.
