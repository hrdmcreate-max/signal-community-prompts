# Code with Claude

**What it helps with:** Start a coding task with a clear goal, a reviewable plan, and permission settings you understand.

**Where to use it:** The included starter prompt works in Claude Code. Claude Code must be installed and signed in through a supported plan or provider. Check the current setup requirements for your operating system.

**What to bring:** The project or repository, the result you want, any constraints or files to protect, your available tools, and any usage or budget limit.

This is an original quick-start reference built from official Claude Code documentation. It does not reproduce the third-party cheat sheet.
