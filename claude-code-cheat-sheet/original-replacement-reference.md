# Claude Code quick reference

A short, original guide to getting started and keeping control of changes. Check official docs for current commands, supported systems, sign-in options, and permission behavior before relying on a remembered shortcut.

- **Start in the project you intend to work on.** Use the setup guide for installation and sign-in, then confirm the installed version.
- **For a plan-first session**, the CLI reference documents `--permission-mode plan`. This helps you review a plan before asking Claude Code to make changes.
- **Review permissions** with the current permission controls before enabling tools or expanding file access.
- **Keep access narrow.** Start from the relevant project and add folders or integrations only when the task needs them.
- **Read proposed changes and commands before approving them.** Claude Code’s permission system is part of how you control edits and tool use. Avoid permission-bypass options as a routine workflow.
- **Keep usage limits in view.** Account plans and API billing vary; check your own plan before long or automated work.

- [CLI reference](https://code.claude.com/docs/en/cli-usage)
